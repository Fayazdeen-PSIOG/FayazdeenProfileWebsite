# Mohamed Fayazdeen — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS and JavaScript**. It presents my background, interests, learning journey and professional experience through a visual, interactive layout.

## Features

- Responsive layout for desktop, tablet and mobile.
- Real Madrid and Manchester United inspired colour themes.
- Interactive navigation and page sections.
- Journey timeline and personal-interest content.
- Custom photography and visual assets.
- Keyboard-accessible interactions and reduced-motion support.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages (hosting)

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

No build step, package manager or JavaScript framework is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload **all files and folders in this repository**. Make sure `index.html` is in the repository's top-level directory.
3. Push the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **GitHub Actions** as the source.
6. Open the **Actions** tab and wait for the **Deploy to GitHub Pages** workflow to finish.
7. Your website URL will appear in **Settings → Pages**.

The repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that publishes the repository root.
